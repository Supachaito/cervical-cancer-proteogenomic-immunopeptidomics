- [ ] Review `CITATION.cff.template`, replace `REPLACE_WITH_USERNAME`, verify software authorship, then rename it to `CITATION.cff`.
- [ ] Verify software authorship/contributors.
- [ ] Choose and add a license compatible with institutional/funder IP requirements.

- [ ] Run the included syntax/path audit before public release.
- [ ] Create GitHub release `v1.0.0`.
- [ ] Archive the release in Zenodo and add the DOI to the manuscript.
